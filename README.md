# Lung Cancer Prediction using Machine Learning

## Overview
This project was developed as part of my Data Science with AI internship at Luminar Technolab. The aim of the project is to predict the likelihood of lung cancer using patient health data and machine learning. By analyzing different health-related factors, the model helps identify whether a person is at risk of developing lung cancer.

## Features
- Preprocessed and cleaned the dataset for better model performance.
- Performed Exploratory Data Analysis (EDA) to understand the data.
- Visualized data using graphs to identify patterns and relationships.
- Built a lung cancer prediction model using the K-Nearest Neighbors (KNN) algorithm.
- Predicted the likelihood of lung cancer based on patient health information.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
- K-Nearest Neighbors (KNN)

## Dataset
The project uses a publicly available lung cancer dataset containing patient health and lifestyle information. The data was cleaned and prepared before training the machine learning model.

## Workflow
1. Loaded the dataset.
2. Cleaned and preprocessed the data.
3. Performed Exploratory Data Analysis (EDA).
4. Trained the KNN model using the processed data.
5. Tested the model and generated predictions.
